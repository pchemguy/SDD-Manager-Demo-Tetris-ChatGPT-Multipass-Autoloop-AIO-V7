# Browser Tetris

A browser-based single-player Tetris project. The repository contains accepted/preapproved development documents for gameplay enhancements; playable application code has not been implemented.

## Project documents

- [Project brief](docs/dev/PROJECT.md): accepted gameplay scope and quality goals.
- [Preparation record](docs/dev/DOCS_PREPARATION.md): six cumulative scopes, proposed interaction decisions, approval boundaries and evidence.
- [Preparation tasks](docs/dev/DOCS_TASKS.md): documentation tasks and checkoffs.
- [Handoff](docs/dev/HANDOFF.md): continuity checkpoint and next eligible action.

## Development and disclosure

This project uses [SDD Manager](SDD-MANAGER.md) for specification-driven preparation and development. See the [AI-assisted development disclosure](AI_DISCLOSURE.md). These notices do not establish that implementation or testing has occurred.
